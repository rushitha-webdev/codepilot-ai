Literature Survey
1. GitHub Copilot

GitHub Copilot is an AI-powered coding assistant that provides real-time code suggestions within code editors. It helps developers write code faster by predicting the next lines of code based on the current context. Copilot improves developer productivity but primarily focuses on code completion rather than understanding an entire software project.

Limitation: It does not perform deep architectural analysis or generate comprehensive documentation for a complete uploaded project.

2. ChatGPT / Google Gemini

Large Language Models (LLMs) such as ChatGPT and Google Gemini assist developers by answering programming questions, explaining algorithms, generating code, debugging errors, and providing software development guidance. Their responses depend heavily on the context supplied by the user.

Limitation: They cannot automatically understand a complete software project without being provided with the relevant source code or project context.

3. Retrieval-Augmented Generation (RAG)

Retrieval-Augmented Generation (RAG) combines a Large Language Model with an external knowledge source. Instead of relying solely on the model's internal knowledge, RAG retrieves relevant documents or source code before generating responses. In software engineering, this enables AI systems to search uploaded repositories and answer project-specific questions with greater accuracy.

Importance: RAG enables CodePilot AI to understand large codebases efficiently and provide context-aware responses.

4. Agentic AI

Agentic AI refers to intelligent systems capable of planning, reasoning, and executing multiple interconnected tasks to accomplish a goal. Unlike traditional AI assistants that respond to one query at a time, Agentic AI can analyze software projects, generate documentation, identify bugs, suggest improvements, and coordinate multiple development tasks autonomously.

Importance: Agentic AI provides the decision-making and workflow automation capabilities of CodePilot AI.

5. Code Analysis Tools

Static code analysis tools such as SonarQube and CodeQL analyze source code without executing it. They detect bugs, security vulnerabilities, coding standard violations, and maintainability issues, helping developers improve software quality.

Limitation: These tools generate analysis reports but lack conversational AI capabilities and do not provide interactive explanations or project-wide understanding.

Conclusion

Existing tools address only specific aspects of software development, such as code completion, bug detection, or AI-based question answering. However, none of them provide a unified platform for comprehensive project understanding. CodePilot AI integrates Retrieval-Augmented Generation (RAG), Agentic AI, and intelligent software analysis into a single platform that enables developers to understand, document, analyze, debug, and improve complete software projects through an interactive AI assistant.
